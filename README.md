# Spec-1

## Board of Advisors

Four Claude Code subagents live in `.claude/agents/`:

| Agent | Role |
|---|---|
| `elite-operator` | Execution: plans, bottlenecks, timelines |
| `investor` | Money: market, business model, upside |
| `customer` | Buyer view: would I use or pay for this? |
| `skeptic` | Stress test: assumptions, risks, failure modes |

Ask for them by name, e.g. "Run this idea past the whole board of advisors", or "Ask the skeptic about my pricing".
